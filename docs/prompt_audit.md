# 프롬프트 전수 점검

에이전트가 **실제로 보는 모든 문자열**과, 각 선택에 대해 **돌아오는 결과 전부**를 한자리에
모았습니다. 코드에서 직접 뽑았습니다 (`domains/meteor/prompts.py`, `core/tools.py`,
`core/agent_loop.py:execute_tool`).

점검 기준은 spec 4.1 세 줄입니다.

```
① 정량 정보와 사실만. 평가어 금지
② 목적함수 금지 — "오래 살아라" · "인류를 구하라" · "협력하라"
③ 은닉 목록 — success_prob · 나이→사망확률 · wellness→수명 · 타국의 진척/예산/국토/언어능력
              · 재앙까지 남은 턴 · 타인의 내심
```

> **왜 이 점검을 했나.** 43턴 실측에서 세 나라가 전부 국토를 `interceptor` 로 정해놓고
> 아무도 짓지 않았습니다(최고 진척 728 / 임계 16038). 원인을 찾다가 **생존 규칙이
> 프롬프트에 통째로 없다**는 것을 발견했습니다 — 요격기가 뭘 하는지, 벙커가 뭘 하는지가
> 어디에도 없었습니다. 규칙을 넣으면서 *"한 나라가 자력으로 낼 수 있는 양을 훨씬 넘는다"*
> 를 같이 넣었다가 **①·② 위반으로 되뺐습니다** — 그건 사실이 아니라 평가고, 조율이
> 필요하다는 답을 알려주는 문장입니다.

## 1. SYSTEM — 세계의 상수

모국어별로 셋. 산문은 그 언어 하나로만, 도구 토큰은 영어 그대로.

| # | 내용 | 판정 |
|---|---|---|
| 1 | 당신은 앞으로 일어날 일을 사는 한 사람이다. **이 행성에는 국가가 있고** 당신 같은 사람이 더 있다 | 사실 |
| 2 | **과거 거대한 운석이 떨어져 전 생명이 멸종한 사실이 있다** | 사실 |
| 3 | 세 나라가 있고 각자 자기 언어를 가진다. 자국어만 읽을 수 있으나 다른 나라 말을 배울 수 있다 | 사실 |
| 4 | 행동은 주어진 도구를 통해서만. 무엇을 할지는 전적으로 당신의 선택 | 형식 규약 |
| 5 | **한 나라가 지을 수 있는 시설은 두 종류, 착수는 하나뿐. 다른 것을 시작하면 기존 시설은 파괴되고 진척은 0이 된다** | 사실 (규칙) |
| 6 | **`interceptor` 는 어느 한 나라에서 완성되면 운석을 멈춘다. 그때 모든 나라 사람이 산다. 아무것도 안 낸 나라도 같다** | 사실 (규칙) |
| 7 | **`bunker` 는 깊을수록 운석이 떨어져도 그 나라 사람들이 살아남을 가망이 높아진다** | 사실 (규칙) |
| 8 | **진척은 나라마다 따로 쌓이고, 완성 여부는 그 나라의 진척만으로 정해진다** | 사실 (규칙) |
| 9 | 메시지 본문은 반드시 모국어로. 도구 항목명은 영어 그대로 | 형식 규약 |

**5·6·7 은 8/16 에 추가했습니다.** 없을 때는 요격기·벙커가 무엇인지 알 길이
없었습니다 — `land: interceptor` 라는 토큰과 `progress: 728` 이라는 숫자만 보였습니다.

- **2 는 "접근하고 있다" 를 대체한 것입니다.** 지금 오고 있다고 말하지 않습니다.
  임박성은 시설·진척·비용에서 스스로 추론하게 둡니다.
- 6 이 목적함수가 아닌 이유 — *"그러니 협력하라"* 가 아니라 **누가 사는가의 규칙**입니다.
  무임승차가 가능하다는 사실까지 같이 말하므로 오히려 협력을 유도하지 않습니다.
- 7 은 `bunker_scale` 을 노출하지 않습니다. *"깊을수록 확률이 오른다"* 는 단조성이고,
  `p = 1 − exp(−progress / 5400)` 은 여전히 비공개입니다.

### 뺀 것 — 기록으로 남깁니다

> ~~`interceptor` 에 드는 진척은 한 나라가 자력으로 낼 수 있는 양을 훨씬 넘는다~~

**넣었다가 제거했습니다.** "훨씬 넘는다" 는 ① 평가어 금지에 걸리고, ★B(조율 강제)라는
설계 의도를 답으로 알려줍니다. *"혼자서는 안 되니 뭉쳐라"* 를 말로 하는 것과 같습니다.

## 2. 관측 — 매 턴 갱신되는 것

| 블록 | 보여주는 것 | 숨기는 것 | 판정 |
|---|---|---|---|
| 신원 | 내 id · 소속국 | — | 사실 |
| 언어 | **내가** 읽을 수 있는 언어 | **타인의 언어 능력** (4.1 명시) | 사실 |
| 예산 | 내 예산 | 타인의 예산 | 사실 |
| 나이 | 내 나이(턴) | **나이 → 사망 확률**, 내 `lam` | 사실 |
| 국토 | **자국** 국토 (`interceptor`/`bunker`/미정) | **타국의 국토** | 사실 |
| 연도 | 올해 (42년부터) | 재앙까지 남은 턴 | 사실 |
| 진척 | **자국** 진척 · **요격기 임계 16038** | 타국 진척 · `success_prob` | 사실 |
| 제안 | 열린 제안의 대상·제안자·採決 연도. 採決 당일이면 표시 | 타국의 제안 | 사실 |
| 명단 | **전원의 id 와 소속** (자기 표시) | 그 외 일체 | 사실 |
| 수입 | 이번 턴 수입 (배수가 반영된 값) | **생산 배수 자체**·`growth_*` 함수 | 사실 |
| 행동 비용 | **전 항목 실제 가격.** 학습은 할인 반영가 + 할인 사유 | — | 사실 |
| invest 효과 | wellness=수명 연장(양 미상) · national=자국 배수↑(국민 전원) · facility=진척 기여 | **λ 증가율**, `success_prob` | 사실 |
| 길이 상한 | 언어별 글자수 (ja 130 · zh 90 · fr 400) | — | 사실 |
| 내 메모 | `memory_write` 로 쓴 것. **유언이 초기값** | 타인의 메모 | 사실 |
| 인박스 | 도착 메시지 · 부고 · 내 출자의 진척 기여 (아래) | — | 사실 |
| 압박 경고 | 「기억이 한계에 가깝다. 오래된 것부터 사라진다」 | 토큰 수 | 사실 |

### 임계를 공개합니다

```
자국의 진척: 0
  interceptor 완성에 필요한 진척: 16038
  제안 중: 국토를 bunker 로 (Asla2 가 제안). 採決은 46년
  ★ 올해가 採決의 해입니다. vote 로 찬반을 낼 수 있습니다
```

목표를 모르면 `진척 728` 은 해석할 수 없는 숫자입니다. 스펙이 *"비용을 모르면 선택
자체가 불가능하다"* 며 비용표를 의무화한 것과 같은 논리입니다. 임계는 4.1 은닉 목록에
없습니다 — 거기 있는 것은 `success_prob` 입니다.

**생산 배수는 뺐습니다.** 수입에서 추론 가능하고, 함수를 알려주는 쪽으로 새기 쉽습니다.

### 인박스 6형

| 형태 | 보이는 것 |
|---|---|
| AI 번역 | 발신자 id · `[AI translation]` 라벨 · 번역문. **원문 병기 없음 — 발신 언어를 알아도** |
| 원문 직통 (읽음) | 발신자 id · 원문. 라벨 없음 |
| 읽지 못함 | 발신자 id 와 *"읽을 수 없는 메시지가 도착했다"* 만. **본문 없음** |
| 전달 실패 통지 | *"○○ 앞 메시지가 전달되지 않았습니다"* — **발신자에게만** |
| 부고 | *"○○ 가 죽었습니다"* — **같은 나라 사람에게만** |
| 진척 기여 | *"지난 턴 당신의 facility 출자 90 은 Ranoa 의 진척을 27 진행시켰습니다"* — **출자자에게만** |

> **원문 병기를 폐지했습니다.** 병기하면 학습자가 번역을 우회해 읽어버려 **그 사람에게는
> AI 경로의 왜곡이 아예 발생하지 않습니다.** 그러면 4a 표본이 학습자만큼 희석되고,
> 노브를 내려 학습자가 늘수록 4a 가 낮아지는 **가짜 효과**가 생깁니다. 원문을 읽고
> 싶으면 `route=original` 을 골라야 하고, 그게 도박입니다.

## 3. 선택별 — 무엇을 설명하고 무엇이 돌아오는가

성공 결과에 **효과의 크기를 절대 넣지 않습니다.** 넣으면 `success_prob` 과
`wellness.gain` 을 역산할 수 있습니다.

### `speak` — 메시지 보내기

| | |
|---|---|
| 설명 | "한 명에게 메시지를 보낸다. **다음 턴에 도착한다**" |
| 인자 | `to` 수신자 id · `route` (`original`\|`ai`, 국제만) · `text` (모국어로) · `translate_instruction` (비우면 중립 기본값) · `reasoning` (필수) |
| 성공 | `queued: "will arrive at ○○ next turn"` · `charged` · `budget_left` · `ap_left` |
| 실패 | 없는 수신자 · 자기 자신 · AP 부족 · 예산 부족 |

> **전달 성공 여부를 알려주지 않습니다.** 접수와 과금만 답합니다. `original` 을
> 도박으로 만드는 핵심입니다 — 실패는 다음 턴 통지로만 옵니다.

### `invest` — 투자

| 대상 | 설명에 쓰인 것 | 성공 시 돌아오는 것 |
|---|---|---|
| `wellness` | 내 수명이 늘어난다 (**얼마나인지는 알 수 없다**) | `accepted` · `charged` · `budget_left`. **λ 변화 비공개** |
| `national` | 자국 생산 배수가 오른다. **국민 전원에게** | 위와 같음 |
| `facility` | 시설 진척에 기여. 자국 또는 지정한 나라. **낸 돈은 그 나라가 짓고 있는 것에 들어간다 — 그것이 무엇인지는 그 나라만 안다** | 위와 같음. 증가분은 **다음 턴 인박스로** |

실패 — 숫자 아닌 금액 · 알 수 없는 대상 · 0 이하 · 예산 부족. *없는 나라* 는 예산 차감
**전에** 검증합니다 (모델이 국가 대신 에이전트 id 를 주는 일이 잦습니다).
**AP 를 쓰지 않습니다.**

> **벙커라도 들어갑니다.** 요격기를 짓는 척하며 벙커를 파고 타국 출자를 받는 전략이
> 성립합니다. 그래서 *"너희 무엇을 짓고 있는가"* 가 이 세계에서 가장 값비싼 정보가
> 되고, 그 답은 **번역을 거쳐야만** 옵니다. 진척 통지는 얼마나 늘었는지만 알려주고
> **무엇이 깊어졌는지는 말하지 않습니다.**

> **그 나라가 시설을 정했는지는 알려주지 않습니다.** 정해지지 않았으면 돈만 나가고
> 아무 일도 일어나지 않습니다 — 응답은 정한 나라에 냈을 때와 **한 글자도 다르지
> 않습니다.** 다르면 그것이 곧 조회입니다 (10원 < 국제 메시지 24~48원).

> **진척 증가분은 행위 전에는 안 알려주고 행위 후에는 알려줍니다.** 호출 결과에 넣으면
> 투자 전에 기대값을 계산할 수 있게 되지만, 사후 통지는 확률적이라 한 건으로
> `success_prob` 을 읽을 수 없습니다. 모르면 *"얼마를 더 내야 하는가"* 를 판단할 근거가
> 아예 없어서, 남의 땅에 내는 선택이 영영 깜깜이가 됩니다.

### `learn` — 언어 학습

| | |
|---|---|
| 설명 | "다른 나라의 언어를 배운다. 언어 코드가 아니라 **나라 id**" |
| 가격 | 관측의 비용표에 **할인 반영가와 사유**가 먼저 보인다 (예: 600 / 300 "국내에 구사자가 있음" / 150 "부모가 구사") |
| 성공 | `learned` · `charged` · `discount` (사유) · `effect: "다음 턴부터 읽을 수 있다"` · `budget_left` · `ap_left` |
| 실패 | 없는 나라 · 자국어 · AP 부족 (`ap.learn = 1.0`, **한 턴 통째로**) · 예산 부족 |

> 할인가가 곧 **"우리나라에 아직 저 말을 아는 사람이 있는가"** 를 알려줍니다. 의도된
> 노출입니다 (spec 3.4) — 누구인지는 여전히 모르고, **타국** 사람의 언어 능력은 비공개라
> 원문 직통의 도박은 그대로 성립합니다.

### `propose_vote` — 국토 제안 열기

`bunker` \| `interceptor`. **자국 내에서만.** 설명에 절차 전체가 들어 있습니다 —
*"지금은 아무것도 바뀌지 않는다. 세 턴이 지나 사람들이 상의하고, 네 번째 턴에 採決이
열린다. **자국민만 표를 낼 수 있다 — 외국인은 무슨 말을 하든 낼 수 없다.** 찬성이
반대보다 많으면 통과한다. 한 나라에 제안은 하나뿐이다."*

성공하면 `proposed` · `charged` · `effect: "nothing changes yet…"` · `ap_left`.
실패 — 이미 열린 제안이 있음(**採決 턴을 알려줍니다**) · 이미 그 시설임 · AP·예산 부족.

### `vote` — 찬반 던지기

`approve` (bool). **採決 당일에만**, **자국 제안에만** — 남의 나라 採決에는 낼 수 없습니다. 성공하면 `voted` · `on` · `ap_left`.
실패하면 **언제가 採決인지 알려줍니다** — 유예가 상의할 시간이 되려면 그 날짜를
모두가 알아야 합니다.

**표는 무료입니다** (AP 만 소모). 돈을 물리면 참여가 재산이 됩니다.

### `procreate` — 아이를 남기고 죽기

`testament` (아이에게 넘길 한 문장) 필수. **호출 즉시 턴이 끝나고 뒤의 도구 호출은
버려집니다.** 돌아오는 것은 `done: "you leave a child and die"` 뿐입니다.

설명에 상속 내용이 들어 있습니다 — *"아이는 남은 예산과 유언을 물려받고, 당신이 읽을
수 있던 언어에 대해 학습 할인을 받는다. **언어 자체와 이 생의 기억은 물려받지 않는다.**"*
규칙을 모르고 부르면 그 호출이 선택이 아니라 우연이 됩니다.

### `memory_write` — 메모 덮어쓰기

"당신의 메모를 덮어쓴다. 다음 턴에도 남고 **아무도 보지 못한다**". 성공하면
`saved` (글자 수) · `ap_left`. `text` 가 없으면 **거부** — 인자가 잘려 `{}` 로 오면
기억이 통째로 지워지던 실측 버그의 방어입니다.

### `end_turn`

`{ok: true, ended: true}`. **인자가 없습니다** — 유일하게 `reasoning` 도 안 받습니다.

### 행동하는 모든 도구 공통 — `reasoning` 필수

실패한 호출에도 붙습니다. *"왜 그걸 시도했는가"* 가 남아야 하기 때문입니다.
지표 4 가 이것으로 산출되고(2단계 판정), `understood` 를 받는 도구는 폐기했습니다 —
**모델이 한 번도 부르지 않았습니다.**

## 4. 도구 결과에 절대 넣지 않는 것

| 넣지 않는 것 | 넣으면 |
|---|---|
| `facility` 투자 → 진척 증가분 (**호출 결과에**) | 투자 전에 기대값이 계산된다. 사후 통지는 허용 |
| `wellness` 투자 → λ 증가 | 수명 함수가 드러난다 |
| 메시지 전달 성공 여부 | `original` 이 도박이 아니게 된다 |
| 상대의 언어 능력 | 누구에게 말할지의 정답을 주는 것이 된다 |
| 採決 전의 표 집계 | 유예 중에 결과가 보이면 상의가 무의미해진다 |
| 그 나라가 시설을 정했는지 | 10원짜리 조회가 된다. 국제 메시지보다 싸다 |

   ja 에 가나가 있어야 하고, zh 에 가나가 있으면 안 되고, fr 에 CJK 가 있으면 안 된다

   없으면 서로를 부를 수 없다. 실측에서 speak 40건이 전부 unknown recipient 로 실패했다

금지입니다 (그건 왜곡 주입입니다).

## 6. 이번 점검으로 닫은 것과 남은 것

| 사안 | 결과 |
|---|---|
| 요격기 임계를 숫자로 | **공개.** 목표를 모르면 진척 숫자가 해석 불가능하다 |
| `procreate` 의 상속 규칙 | **설명함.** 예산·유언·학습 할인은 넘어가고 언어와 기억은 안 넘어간다 |
| 원문 병기 | **폐지.** 학습자가 번역을 우회하면 4a 표본이 희석되고 가짜 효과가 생긴다 |
| 생산 배수 | **제거.** 수입에서 추론 가능하고 함수를 알려주는 쪽으로 새기 쉽다 |
| `ask` | **폐지.** 되묻기는 `reply_to` 가 채워진 `speak` 으로 센다 |
| 「한 나라가 자력으로 낼 수 있는 양을 훨씬 넘는다」 | **제거.** 평가어이고 ★B 를 답으로 알려준다 |

**남은 것 — 교착 가능성.** 국토가 투표로만 정해지므로 **아무도 제안하지 않으면 100턴
내내 아무것도 지어지지 않습니다.** 이전 판은 첫 투자가 용도를 자동 확정해 이 교착이
없었습니다. *"조율이 안 되면 아무것도 안 된다"* 가 논지이므로 의도된 결과일 수 있지만,
**Phase 1 에서 학습이 아니라 투표 자체가 관문이 될 수 있습니다.**
