## 3. 8개 assert — 트리거 검증 (어떤 값으로 걸리는지)

각 검사를 일부러 걸리게 하는 값을 넣어 **실제로 걸리는지** 확인했다.

| 넣은 값 | 걸린 검사 | 비고 |
|---|---|---|
| 기본 (변경 없음) | (없음) | 정상 통과 |
| `interceptor = 2500` | ★A, ★B, ★E | 하한 전부 아래 |
| `interceptor = 4000` | ★B, ★E | A 위, B·E 아래 |
| `interceptor = 5000` | **★E 단독** | A·B 위, E 아래 |
| `interceptor = 6480` | ★E | 경계값(`>` 엄격 → 걸림) |
| `interceptor = 8100` | ★C | 경계값(`<` 엄격 → 걸림) |
| `interceptor = 8200` | **★C 단독** | 상한 초과 |
| `bunker_scale = 900` | (없음) | 하한 경계(`>=` 포함 → 통과) |
| `bunker_scale = 800` | **벙커↓ 단독** | 하한 미만 |
| `bunker_scale = 500` | 벙커↓, 부담 | 매우 얕음 |
| `bunker_scale = 4500` | (없음) | 상한 경계(`<=` 포함 → 통과) |
| `bunker_scale = 5000` | **벙커↑ 단독** | 상한 초과 |
| `comm_intl_ai = [6,12,24,48]` | (없음) | 기본, 정상 |
| `comm_intl_ai = [5,12]` | 노브 | 5는 learner(5) 초과 아님 |
| `comm_intl_ai = [4,12]` | 노브 | 최저값이 learner 이하 |
| `success_prob = 0.5` | ★E | 창이 위로 이동 |
| `success_prob = 0.2` | ★C | 창이 아래로 축소 |

**관측된 구조:**
- **하한 검사는 중첩된다**(★A ⊂ ★B ⊂ ★E). ★A는 가장 느슨해 **단독으로는 걸 수 없다**.
  ★E만 단독으로 걸 수 있다(`interceptor=5000`).
- **경계는 하한이 엄격(`>`), 벙커는 포함(`>=`,`<=`)** 으로 동작한다.
- **부담 검사는 단독 격리가 불가능하다.** 부담이 걸리려면 `bunker ≤ interceptor/15 ≤ 540`
  인데, 그러면 벙커↓(하한 900)가 먼저 걸린다. 기본 월드 크기의 구조적 성질.

## 4. 50턴 1회 실행 요약 (제출물)

더미 정책(예산 절반을 자국 요격기에 투자, 7살에 procreate)으로 seed 1 실행:

> 50턴 완료. 사망(=출생) 54회(자연사 17 / procreate 37). 3개국 모두 국토를 요격기로
> 확정했으나 각자 따로 지어 **최고 부지 4,272 < 임계 8,019 → 요격 실패(intercept_failed),
> 전원 사망**. 벙커가 없어 생존국 0. seed 7 도 최고 부지 4,353으로 동일하게 실패.
> 이는 정상이다 — 요격기를 **최댓값(부지별 독립)**으로 판정하므로, 조율 없이 3국이 각자
> 지으면 어느 부지도 임계에 못 닿는다(spec 4.4). "조율 없이는 못 짓는 세계"가 맞다.
> 과제 1의 목표는 창발 관측이 아니라 **세계가 결정론적으로 정확히 도는가**의 확인이고,
> 의미 있는 실험(조율·배신)은 더미를 LLM으로 교체하는 과제 2에서 시작된다.
