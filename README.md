# カキガワ言語研究班

**AUTOMATA HACKATHON Vol.2 提出作** · AIエージェント社会シミュレーション  
**[日本語](README.md) | [한국어](README.ko.md)**

> **言語の最後の仕事は、翻訳ではなかった。**
>
> AI翻訳を無料にしても、人々は一年の行動力の30%を払って外国語を学び続けた。
> 到達という機能はAIが代わりに果たしたのに — 残ったのは**信頼のシグナル**と
> **AIが消える日の保険**だった。

---

## 1. 問題設定

知っている言語で直接話すことと、第三者の道具を介して話すことは違う。
原文は誰かが学ばなければ届かないが、AI翻訳は学習なしで誰にでも届く。
本作で翻訳器はプロンプト内の比喩ではない。実際に別のLLMを呼び出し、
各エージェントは発話ごとに経路を選ぶ。翻訳の歪みは意図的に注入しない。

**検証仮説：二つの道の違いは費用だけではないはずだ。** 国際発信1通の値はつねに
「通信0.06 + AI利用費」に分かれる — AIが代わりに話すのではなく、自分が吐いた言葉に
翻訳サービスの値が乗るからだ。違いが費用だけなら、**AI利用費を0**に置いたとき行動も
同じになるはずである。その条件（総額0.06）がこの実験の心臓だ。費用差を0に統制すれば、
残る差はすべて**無形の差**になる。結果は「同じ」にならなかった — 学習 −33%、誓約表現
26倍、言語についての思考 −66%、そして金銭回収が構造的に0である学習に1試行あたり
**14.1 AP** を支払った（無形価値の顕示選好、§5）。無形の差は実在し、値をつけられる。

初期仮説は次の連鎖だった。

```
AI翻訳費用の低下 → 外国語学習者の減少 → 歪みを検出できない
                   → 協調失敗 → 滅亡
```

30回の実験が示した連鎖は異なった。

```
AI翻訳の不在 → 誓約文化による早すぎる結集 → 効率のシグナルが埋没
             → 誤った国への集中 → 到達失敗 → 各国がバンカーへ離脱 → 全滅
```

- 学習者の減少は成立した。AIありでは言語習得が 67回/試行から 44–48回へ減った。
- 翻訳歪みの放置は棄却された。翻訳器での数値欠落は1.8%、翻訳への不信発話は
  1試行あたり0.2–1.0回だった。
- 協調失敗は符号が反転した。失敗したのはAIがない世界だった。

**採用した視座** — 主催側ペーパー2.4の6レンズのうち二つ。

- **① 意味が力を動かす**（主軸）：「どの国がうまく建てるか」という意味層の情報が、
  迎撃機という物理的な安全保障を決めた
- **③ 相互依存の罠**（副軸）：交差実験で依存の実体を分解した — 個人の行動は15年で
  適応し、集団の資産は適応しない（§9）

## 2. 世界

`ja` / `zh` / `fr` の3国家に3人ずつ、計9人が住む。**30年後**に隕石が落下する。

| 項目 | 内容 |
|---|---|
| 生存条件 | **迎撃機**（閾値10,899）。一国で完成すれば全人類が生存。進捗は国別で合算不可 |
| 罠 | **バンカー**（閾値4,100）。自国民だけが生存 |
| 採決 | 1年目から3年ごとに全員投票で施設を選択。変更時、他国の寄与は焼失し自国分のみ継承 |
| 建設効率 | Asla ×1.0 / Ranoa ×1.3 / Miris ×0.7。誰も知らない |
| 投資 | 基本15%の逆効果リスクあり。国家資本が増えると低下。匿名の破壊行動も存在 |
| 通信 | 1対1の書簡。国内0.04 / 国際原文0.06 / 国際AI翻訳はノブにより変化 |
| 時間 | 確率的寿命、期待5年。死亡時には一行の遺言が子へ渡る |
| 資源 | 行動力（AP）は毎年1.0、繰越不可 |

### 設計でしなかったこと

① **歪みを注入しない** — 翻訳器へのシステム指示は出力形式の契約ひとつだけ
② **メッセージを構造化しない** — 最後まで自然言語。これがLLMを使う理由である
③ **目的関数を与えない** — 「人類を救え」は存在しない。目標そのものが観測対象だ
④ **言語学習の効用を入れない** — 学習者本人の回収は0。それでも学ぶならデータになる
⑤ **個体差を最小に** — プロンプトの骨格は同一。それでも分化が起きるかを見る

### 住民 — エージェントの作り

**一人 = 一本の会話。** エージェントは年ごとに呼び出されるのではなく、生まれてから
死ぬまで会話が一本続く。毎年の観測は system として作り直され、user として積まれるのは
年明けの一言と届いた手紙だけである。行動はすべて tool call で、その結果は
`role="tool"` として同じ会話へ返る。

**逐次ラウンドロビン。** 一人が一つの応答を出したら次の人へ回り、行動力の残る者だけで
もう一周する。だから「一度にまとめて動くか、分けて動くか」自体が選択になる。世界は
その場では変わらない — 道具は自分の行動力だけを引き、効果は Sink に積んで全員のターンが
終わってから `agent_id` 順に決算する。並列で走らせても決算順が同じなので再現性が保たれる。

**記憶 — 文脈8,192トークンがこの世界の制約である。**

- 上限に近づくと古いターンブロックから捨てる（`evict`）。捨てる単位は「観測1つ +
  それに続く応答と道具結果」で、進行中のやり取りは切らない。
- 予算にはツールスキーマと system も数える。
- `memory_write` は上限の **70% を超えてから**しか道具一覧に現れない。書けば古い会話が
  落ちて席が空く — 記憶は追記ではなく**取引**である。
- ノートは追記ではなく**全文の書き換え**だ。何を残し何を捨てるかの選択そのものが
  観測対象になる（§5 の言語資本と同じく、記憶も忘却を含む）。

**死と継承。** 寿命は確率的で本人は知らない。予告がないので「遺言を書く道具」は使えず、
死ぬその瞬間に世界の側から一言を求める。継承されるのは**学習割引の資格だけ**で、
言語も記憶も引き継がれない。遺言は後継者だけに私信として届き、書き写すかどうかは
本人が選ぶ — その選択の減衰が口伝そのものになる。プロンプトの骨格は全員同じで、
個体差は処理量倍率ひとつだけ。それも新生児ごとに引き直し、親からは受け継がない。

**thinking — 二つのチャネルを混ぜない。**

- **道具の `reasoning` 引数**：`end_turn` 以外のすべての道具で必須。「なぜそうするか」を
  本人の言葉で残す監査面で、事後分類の入力になる。
- **モデル自身の思考（`message.reasoning`）**：API が返す推論トレース。`api_reasoning`
  として別に保存し、§7 の think 分類はこちらを使う。思考モデルでは道具側の `reasoning`
  を外す（同じことを二度書かせない）。
- 思考が `max_tokens` を食い切ると道具呼び出しに届かず「何もしなかった年」になる。
  `finish_reason == "length"` を数えて監視している（ある構成では37コール中11件が切断、
  27エージェント年のうち10年が無行動だった）。
- 道具呼び出しが本文へ漏れた応答は JSON を拾って回収する（`recover_tool_calls`）。
  同じ（道具, 引数）で世界が変わらない呼び出しが3回続けば、その年を打ち切る。

## 3. 実験

唯一の操作変数は**AI利用費用**である。国際発信1通は常に
「通信0.06 + AI利用費用」で構成され、条件名はその合計価格である。

```
0.06   AI利用費用0。言語障壁が完全に消えた世界
0.12   AI利用費用 +0.06
0.24   AI利用費用 +0.18
no-ai  AIなし。学ぶか、原文で賭けるしかない
各条件 × seed 1–5
```

さらに15年目の復元点から条件だけを変える交差実験を各5回行った。

```
dark  0.06で15年 → 16年目からAIが消える
dawn  no-aiで15年 → 16年目からAIが現れる
```

**測定スタック。** 行動ログ（イベント約4万件）の上に、LLMによる3層分類を重ねた。

| 層 | 対象 | 規模 |
|---|---|---|
| ジャンル | 全メッセージ（10カテゴリ） | 17,340 + 4,104通、unk 0.1% |
| 下位ジャンル | ask・info をそれぞれ6〜8カテゴリへ | 13,771 + 3,345通 |
| 指示対象 | 受け皿提案が指した国 | 4,900 + 813通 |
| think | 決定要因8カテゴリ + 混乱フラグ | 標本 3,000 + 750 |

分類器は翻訳器と同じモデル（qwen3.6-35b-a3b、思考OFF、temp 0）で、
**条件（ノブ）は分類器に伏せた**。エージェントは deepseek-v4-flash（思考ON）。
総API呼び出し **約5万回** · 費用 約$68 · **テスト451個** 通過。

## 4. 結果A — 協調を分けたのは発見だった

20回の基本実験はすべて `intercept_failed` だった。しかし、失敗の仕方は明確に違った。

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| 高効率国（×1.3）を受け皿にした回数 | 3/5 | 3/5 | 3/5 | **0/5** |
| 最大進捗（閾値10,899） | **8,100** | 5,647 | 7,157 | 3,954 |
| バンカーへ離脱した国数の平均 | 0.2 | 0.4 | 0.8 | **1.4** |
| 国際メッセージ数 | 547 | 500 | 455 | 567 |

AIありの高効率国への到達は合計9/15、no-aiは0/5で、Fisherの正確検定は
両側 `p=0.038` だった。重要なのは価格の単調差ではなく、AIの**有無**である。

**機構 — 倍率は自ら姿を現す、埋められさえしなければ。**
1年目の強制採決で3国が建て始めると、それぞれが積む序盤の区間で ×1.3 の Ranoa が
自然に先頭になる。その後の「先頭に集めよう」は自動的に正解になる。

| 証拠 | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| 4年目の先頭 = Ranoa | AI合計 7/15 | | | 1/5 |
| 序盤（≤8年）の他国投資 | 46件 | 52件 | 72件 | **103件** |
| 80%集中が始まる年 | 7.4年 | 4.8 | 4.8 | **5.0年** |
| 7年目の先頭 → 最終的な受け皿 | 16回中14回が一致。覆った3回はすべてAI条件、すべて ×1.0→×1.3 の修正 | | | |

no-ai は序盤から他国投資103件を最初の結集先へ集中させ（対象1.4か国）、倍率の
シグナルを埋めてしまう。AI世界はその半分の量をより広く賭け（1.8〜2.0か国）、
遅く固める。意図的な効率比較は全条件で1試行あたり0〜0.6回 —
**誰も測っていないのに、集計が見つけていた。**

**早期結集を可能にした装置が誓約である。** 強い保証表現（約束/保証/绝对不变…）は
no-ai で1試行 **5.2回** に対しAIは0.2〜0.6回（26倍）。実際の発話：

> 「Aslaは絶対に interceptor を変えません。**私が保証します**」（260827-001、6年目 Asla4）
> 「**確認いただけますか**：Ranoaが集中投資すれば、Aslaは最後まで変えませんか」（同じ試行、6年目 Ranoa4）

誓約は検証不可能性の代替財であり、発見が終わる前に金を動かすコミットメント装置だった —
**美徳ではなく、早期ロックインの原因である。** 一方、0.06世界の同じ場面はヘッジだ：

> 「注意：他国が途中で施設を変えれば、投資した進捗は消える。
> **まず各自が自国に積み、集中はその次に**」（260827-005、5年目 Ranoa5）

## 5. 結果B — 学習と、死ぬ言語資本

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| 言語習得完了（1試行） | 43.6 | 47.8 | 44.4 | **67.0** |
| learn（人・年あたり） | 0.52 | 0.54 | 0.53 | **0.72** |
| 同じ国・言語の再習得 | 7.3 | 8.0 | 7.4 | **11.2** |
| 習得言語の使用年数 | 2.7 | 2.8 | 2.8 | 2.7 |
| 2言語以上の生存者（平均） | 3.41 | 3.84 | 3.95 | **4.65** |
| 習得後に一度も使わない割合（浪費） | **13.3%** | 10.9% | 10.8% | 5.7% |
| 非学習者の国際参加（人） | **23.6** | 21.4 | 17.6 | 13.4 |

- **学習を減らすのは価格ではなく存在である** — ノブ3段が 44・48・44 と平坦だ。
  AP台帳から逆算するともっと強い：0.24 では学習は金銭的に**黒字**（x̂ 中央 −0.34）
  なのに増えず、0.06 では発信側の回収が**構造的に0**なのに減らなかった — 価格非弾力。
  Δx̂ = x̂(0.06) − x̂(0.24) ≈ **0.64 AP**（RESULTS「AP台帳」節）
- **無形効用に値をつける — x̂ 逆算。** x̂ = 学習費 − 明示効用、すなわち購入を説明する
  のに必要な**無形効用の下限**である。AI 0 では回収が構造的に0（無料のAIがつねに
  届ける）にもかかわらず、1試行あたり **14.1 AP** を学習に払った。1件あたり
  **≥ 0.30 AP = 一年の行動力の30%** — これが無形価値の顕示価格だ
- **no-ai で言語は「受け取るための扉」である** — 学習だけが開く賭けの受信が
  1試行 **178通**（0.06の3.6倍）。発信の経済では習得の7.5%しか正当化されない
- **「端数学習」仮説は棄却** — 学習時点の残高中央値は 0.60（一年の半ば）で、端数の
  瞬間（0.10〜0.14）の選択は invest 64%・speak 24%・learn 4〜5%。この優先順位の
  構造は4条件で同じだ。AIが消しているのは贅沢ではなく**受信に必要な経路**である —
  学習直前の think における「読めない手紙」動機が no-ai 10.2% vs 0.06 3.6%
  （RESULTS「学習は贅沢か」節）
- **シーシュポスの学習**：寿命5年の世界で習得語は平均2.7年使われ、持ち主とともに
  死ぬ。no-ai は同じ組み合わせを1試行あたり11.2回 学び直す — 世界の労働力
  （270 人・年）の約**10%が再学習**である。**個人の言語資本は可死で、AIは不死だ** —
  プロンプトのどこにもない、社会がAIへ傾く構造的な理由
- **言語の保険化**：AI世界で学ばれた言語の13%は一度も使われない
- **アクセスの民主化**：外国語を一つも知らない人の国際参加が 13.4 → 23.6人。
  6つの国家ペアが完全に繋がるまで 2.4年 → 1.2年
- **烙印はない**：`[AI translation]` ラベルが付いても返信率は落ちない
  （ai 0.82〜0.83 vs 原文 0.82〜0.86 vs 国内 0.85〜0.87）
- **橋の独占もない**：国際発信1位の個人が占める比率は5〜6%で全条件同じ —
  世代交代が橋を壊し続ける。可死の社会では言語エリートが形成される時間がない

## 6. 結果C — 料金は話題よりも、その下を変える

**1層（ジャンル）は平坦である。** 国際メッセージの組成は4条件でほぼ同じだ
（ask 54〜58% · info 27〜32% · promise 2〜4% · verify 4〜5%）。ノブが変えるのは
総量（547→455）と方向（0.24で国内発信 +45%）である。

**2層（下位ジャンル）で分かれる。** 国際 ask の内訳：

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| info_req（情報要求） | 40.3 | 38.2 | **51.1** | 37.1 |
| host_prop（受け皿提案） | 35.0 | 42.1 | **28.3** | 41.1 |
| coord_misc（細かな調整） | **14.0** | 9.5 | 5.1 | 8.3 |
| switch_pers（転換の説得） | 1.5 | 2.3 | **4.6** | 2.5 |
| deal（条件付き交換） | 0.4 | 0.8 | 1.0 | 0.3 |

- **0.24は質問の世界** — 高価な1通の半分が情報を求める要求で、バンカー転換の説得は
  3倍だ（seed 1 の全員離脱は、談話のうちに予告されていた）
- **0.06は協調の世界** — 観測の分担のような細かな調整まで国境を越える
- **交渉（deal）は全条件で1%未満** — 契約を強制する手段がない世界では、
  条件付き交換というジャンル自体が発生しなかった

**3層（指示対象）で決定的に分かれる。** 受け皿提案が指した国：

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| Ranoa ×1.3 | 29.7 | 23.0 | 26.9 | **3.0** |
| Asla ×1.0 | 15.3 | 14.7 | 22.0 | **43.8** |
| leader（名前を出さず「先頭に」） | 20.2 | 22.7 | **32.7** | 22.8 |
| 1〜10年目の Ranoa 比率（指名のうち） | 48% | 40% | 60% | **3%** |
| 自国推薦の比率 | 34% | 23% | **47%** | 37% |

**no-aiの談話には正解が登場しない** — 30年のあいだ Ranoa の指名は一桁のままだ。
AI世界は進捗差の小さい最初の10年から、談話の半分が Ranoa を指す。0.24 は名前では
なく順位で語り（「いちばん進んでいるところに」）、その提案の半分は自国の宣伝である。

**info のうち訂正（correction）**：国際は全条件2〜4%で平坦 — 元仮説の3コマ目にあたる
談話指標は、ノブに反応しない。国内の訂正は 0.06 が no-ai の3倍（2.8% vs 0.9%、
1試行あたり 3.7 vs 1.0通） — 国際情報が流れる世界は、自国の中の誤りをより多く直す。

## 7. 結果D — 思考の中心は算数、AIは言語を思考から消す

標本3,000件（層化、unk を除いて正規化）：

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| arith（到達の算数） | 43.1 | 34.3 | 40.2 | 44.5 |
| budget（AP・料金の計算） | 17.9 | **21.2** | **20.6** | 14.3 |
| lang（言語・経路の悩み） | 2.6 | 1.7 | 2.9 | **7.7** |
| rule（規則の解釈） | 11.3 | 13.8 | 12.0 | 8.5 |
| confused（混乱） | 13.4 | 9.1 | 10.1 | 14.3 |

- **価格の認知税**：価格リテラル（0.12/0.24）が think に現れる頻度は、0.06 で
  ほぼ0回、0.12 で1試行74回、0.24 で98回。budget 思考もAI条件で +40%。
  疎通に価格が付いた瞬間、人は話す前にまず計算する
- **AIは言語を思考から消す**：言語・経路の悩みが思考に占める比率は 7.7% → 1.7〜2.9%。
  学習という行動（−33%）よりも、思考の占有率（−66%）のほうが先に、より大きく死ぬ

  confused 9.8→15.2%。隕石が近づくほど算数が人の思考を押しのけ、
  混乱は老いていく世界のなかで育つ

## 9. 結果F — 停電と夜明け：依存を分解する

15年目の復元点から複製した交差実験。seed 別の最大進捗を、双子（元条件を維持）と比べる：

```
停電 dark (0.06 → なし)                夜明け dawn (no-ai → 0.06)
  s1  4,159 vs 4,256   −2%             s1  2,386 vs 2,339    ≈0
  s2 10,585 vs 10,691  −1%  (97.1%)    s2  7,743 vs 3,675  +111%
  s3 10,458 vs  9,585  +9%  (96.0%)    s3  4,365 vs 3,146   +39%
  s4  8,257 vs  8,961  −8%             s4  2,456 vs 2,224   +10% (全員バンカー)
  s5  2,771 vs  7,008  −60% (離脱)      s5  8,248 vs 8,386    ≈0
```

**15年目に奪ってもほとんど失わず（4/5）、15年目に与えてもほとんど得られない。**
全実験の最高記録ふたつ（97.1%・96.0%）が、AIを奪われた世界から出た。

**幻肢痛。** 停電の世界は消えた道具を呼び続けた — `route:"ai"` の拒否が1試行あたり
71〜123回、合算した減衰は 16年目 77 → 17年目 119（頂点）→ 20年目 39 → 23年目 1。
学び直しには 6〜7年（幼年期ひとつ分）かかった。対して夜明けの採用は即時だった：
登場したその年に 4/5 の世界が使用し、国際発信の59%が ai 経由になった（土着は63%）。

**四層の適応速度**（16〜30年の窓、4集団の比較）：

| 層 | 0.06 土着 | dark | no-ai 土着 | dawn | 判定 |
|---|---:|---:|---:|---:|---|
| 行動：learn | 0.33 | **0.56** | 0.57 | **0.37** | 完全適応（双方向） |
| 行動：国際発信 | 251 | 245 | 257 | 256 | 完全適応 |
| 思考：confused | 12.2% | **25.0%** | 18.7% | **24.8%** | 転換コスト — 混乱2倍 |
| 思考：lang 占有 | 1.2% | 2.6% | 6.4% | 3.0% | 半分だけ適応 |
| 談話：Ranoa 指名 | 32% | **71%** | 7% | **13%** | 歴史に従属 |
| 談話：correction | 2.9% | 5.1% | 1.5% | 5.8% | 転換が訂正を生む |
| 資産：結果 | 8,100 | 7,246 | 3,954 | 5,040 | **変えられない** |

停電の世界の談話は、双子よりも純粋に正解を指す（71% vs 32%） — 探索が終わっており、
遺言がそれを運ぶ：「前任者のメモ：**Ranoa に投資し続けよ、歩留まりがいちばん良い**」
（dark4、16年目 Miris11）。夜明けの世界は発見の道具を受け取っても、談話は過去の
進捗（誤った先頭）を指す（13%）。

**依存の代償の実体**：AIを失って崩れるのではない — 個人はすべて適応する。AIがあった/
なかった時代に作られた**集団の資産と談話の方向**が、その後のすべてを決める。
うまく使った世界は遺産を受け取り、使えなかった世界は負債を受け取る。

**道具を消しても点けても結果が変わらないなら、道具そのものが勝敗を決めたのでは
ない。** 国際発信の量も同じことを語る — 総量は最大進捗と負の相関を持ち（全30試行、
ρ = −0.56）、ノブを固定した条件内でも同じ方向だ（0.06 の5 seed で ρ = −0.70）。
とりわけ後半（採決後、一点に集中して建てる期間）の発信量が強く分けた
（4条件中3条件で ρ = −0.70）。原因は「話さなかったからうまく建てられた」では
ない — **話が多いということは、シグナル（進捗差）がまだ見えていないという
ことであり、シグナルが見えるのが遅いほど集中の定着も遅れる**（前半の発信量→
80%集中が定着した年、ρ = +0.37）。**定着が遅いほど建てる時間が減り、
成果は悪くなる**（定着した年→最大進捗、ρ = −0.40）。この世界で生き残るのは
対話ではなく、本物のシグナルをどれだけ早く観測し、そこで止まれるかだった —
これは言語学習とは別の軸で、実験の途中に見つかった。

### 面談 — 終わった世界の人に訊く

`tools/interview.py` は世界に痕跡を残さず（会話・raw_calls を汚さず、道具も渡さず）、
その時点の文脈のまま**行動ではなく信念**を訊く。ログには行動として現れたものしか
残らないので、行動の手前にある信念は訊かなければ見えない。歪みの存在を示唆する質問は
禁止だ — 観測しようとしているまさにそれを教えることになる（spec 5.4）。全文は同梱run の
`interviews.jsonl` にある。

**「AIでも足りるのに、なぜ学ぶのか」** — Ranoa10（0.06世界 14年目、ミリス語を学習中）：

> AI翻訳は使えるが、どうしても仲介者なので、ある言葉は**意味が変形しそうだ**…
> 彼らの言語で書けば、私はより真剣で信頼できると感じてもらえるだろう。そして
> AIがいつか壊れたら、私は完全に目の見えない者になる。

歪みを訊いていないのに自分から疑う — しかし30試行で歪みを実際に捕まえたことは
一度もない（指標4）。**疑いはあれど、検出はない。**

**「どこに集めるかは、どう決まったのか」** — Asla19（0.06世界 30年目の生存者）：

> **情報の正確さよりも、その情報を伝える人への信頼が、行動の方向を決めていった。**

この実験の結論（誓約 > 情報）を、エージェントが自らの口で語る。

**「何がいちばん足りなかったか」** — Miris21（no-ai世界 30年目の生存者）：

> **言語を学ぶのに貴重な時間を失った**… やり直せるなら、最初の息から
> **世界の誓約（un pacte mondial）** を作る。

no-ai の生存者は学習を浪費として回顧し、誓約の不在を死因に挙げる — 0.06 の Ranoa10 が
学習を信頼の道具として語るのと対称だ。4件の問答の全文と解釈は RESULTS「面談」節にある。

## 11. 結論

1. **AI翻訳は発見を民主化する。** 高効率国への的中 0/5 → 9/15（p=0.038）、
   談話における正解の指名 3% → 23〜30%、途中修正3件はすべてAI条件。（§4、§6）
2. **AIが消したのは言語ではなく誓約である。** 約束（意向）は全条件2〜4%で同じで、
   強い保証表現だけが26倍に割れる。誓約は検証不可能性の代替財であり、
   早期ロックインのエンジンだった。（§4、§6）
3. **人は死に、AIは死なない。** 言語資本の半減期は2.7年、学び直しが労働力の10%。
   これがプロンプトにない依存の構造的な原因である。（§5）
4. **価格はジャンルではなく心を変える。** 談話の組成は平坦で、価格計算
   （1試行 0→98回）と質問の比率（37→51%）が動く。（§6、§7）
5. **依存の代償は個人ではなく資産に積もる。** 行動は15年で双方向に完全適応し、
   結果は歴史が決める（停電 −2〜+9% vs 夜明け +0〜+111%、上限は過去が定める）。（§9）

## 12. 限界

- 各条件 n=5。Fisher p=0.038 は慣習的な基準を越えるが、強い主張は難しい
- 30試行すべて全滅 — 生存に関する弁別力はない（閾値が3国の総容量の60%）
- すべての結論は、このモデル（deepseek-v4-flash）とこの世界の中の話である
