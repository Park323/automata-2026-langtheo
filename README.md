## 검증하는 연쇄 — 한 줄

```
AI 번역 비용 하락 → 외국어 학습자 감소 → 왜곡을 알아채지 못함 → 조율 실패 → 멸망
```

칸이 다섯이고 **지표가 각 칸에 하나씩** 대응합니다. 어느 칸에서 끊기는지가 결과입니다.

**채택한 시좌** — 주최측 페이퍼 2.4의 6렌즈 중

- **① 意味が力を動かす** (주축) — 번역 왜곡이라는 *의미* 층위가 요격기 건설이라는 *물리적 안보*를 결정합니다
- **③ 相互依存の罠** (부축) — AI 번역은 평시에 편의이고 유사시에 취약성입니다

## 세계

3개 국가(`ja` / `zh` / `fr`), 각 3명, 총 9명. 50턴 뒤 운석이 떨어집니다.

|  | 내용 |
|---|---|
| 살아남는 법 | **요격기** — 3국이 한 부지에 모아야 도달. 전 인류 생존 |
| 함정 | **벙커** — 자국만. 깊이에 따른 확률이고 100%에 닿지 않음 |
| 소통 | 1:1 서신. 국내 / 국제 원문직통 / 국제 AI번역 세 경로 |
| 시간 | 세대 경계 없음. 확률적 수명(기대 8.3턴) |

**언어를 배우면 원문을 읽을 수 있고, 원문을 읽으면 왜곡을 검출할 수 있습니다.**
배우지 않으면 AI 번역만 읽고, 무엇이 깎였는지 알 수 없습니다.

---

## 설계에서 하지 않은 것

이 실험의 성격은 **무엇을 넣었는가**보다 **무엇을 넣지 않았는가**로 정해집니다.

**① 왜곡을 주입하지 않습니다.**
프롬프트에 "왜곡하라"를 넣으면 결과가 설정의 귀결이 됩니다. 시스템이 번역기에 주는 지시는 **출력 형식 계약 하나뿐**이고(`"번역문만 출력하라"`), 번역 방식은 **발신 에이전트가 직접 씁니다.** 지시가 없으면 중립 기본값 `"번역하라"` 만 씁니다 — 여기에 *"간결하게"* 를 넣으면 우리가 왜곡을 주입하는 것이 됩니다.

번역은 **언어 간 직역**입니다. 초기 설계는 영어를 중계 언어(pivot)로 두고 2단 번역을 거쳤지만 폐기했습니다 — pivot을 고른 이유가 *"손실이 두 배가 되어서"* 였고, 그건 의도 주입입니다. 그리고 지금 LLM은 직역합니다. 직역이라 **6개 언어쌍 방향이 각각 다른 손실·생성 프로필을 가지고, 언어쌍 자체가 대조군이 됩니다.**

**② 메시지를 구조화하지 않습니다.**
`{수량: 3, 순서: [...]}` 같은 필드로 바꾸면 번역 손실이 데이터 손실이 되어 엑셀로도 되는 실험이 됩니다. **끝까지 자연어입니다.** 이것이 LLM을 쓰는 이유입니다.

**③ 목적함수를 주지 않습니다.**
"오래 살아라", "인류를 구하라" 같은 지시가 없습니다. 주면 이타적 행동이 *발견*이 아니라 *지시 이행*이 되어 해석이 불가능해집니다. 운석과 비용표만 보여주고, 무엇을 목표로 삼았는지는 `reasoning`을 사후 분류해서 관측합니다.

**④ 언어 학습의 효용을 넣지 않습니다.**
`known_langs`는 *읽을 수 있는* 언어 집합이고 원문 직통의 실패 조건은 *"수신자가 못 읽으면"*입니다. 메시지는 발신자 언어로 쓰이므로 **학습자 본인의 예산 회수는 0입니다.** 학습은 순수한 공공재이고, 그래도 배운다면 그건 우리가 넣지 않은 암묵 효용 `x` 때문입니다.

```
학습이 일어남  ⟺  x ≥ 실제 학습비 ∈ {L, L/2, L/4}

x̂(노브) = 그 조건에서 학습이 켜지고 꺼지는 학습비 임계
Δx      = x̂(AI 비쌈) − x̂(AI 쌈)      ← 연쇄 1~2칸의 정량 진술
```

**`x`는 우리가 정하는 값이 아니라 시뮬레이션에서 읽어내는 값입니다.**
*"AI 번역이 싸지면 언어 학습의 암묵 가치가 얼마나 깎이는가"* 에 **가격 단위로** 답합니다.

**⑤ 개체차를 두지 않습니다.**
전원 동일한 프롬프트 골격, 동일한 초기값입니다. 동일한데도 분화가 일어나는지가 관측 대상입니다.

## 의도된 설계 두 가지

결함으로 읽힐 수 있어 미리 밝힙니다.

**늦게 태어난 사람은 앞사람에게 의존합니다.** 요격기 임계는 마지막 한 주기에 3국이 전력을 다해도 못 넘게 잡혀 있습니다(★A). 후반에 태어난 에이전트는 앞사람이 쌓아둔 더미를 마무리할 수만 있습니다. 세대 간 공공재의 정확한 재현이며, 세대 경계를 없앤 덕에 이 무력함이 **연속적**입니다.

**아무도 투자하지 않아 멸망하는 결말을 막지 않았습니다.** 공공 투자에 즉각 보상을 얹는 장치(warm glow)를 폐지했습니다. 보상을 주면 목적함수를 주는 것에 가깝기 때문입니다. 다들 자기 수명만 늘리다 아무것도 못 짓고 죽는 것도 현실적인 결말이고, 그 자체가 결과입니다.

## 지금까지의 결과

### 번역 경로 파일럿 (완료)

**엔진을 만들기 전에** 번역에서 화용 자질이 실제로 깎이는지 확인했습니다. 324콜, 6방향 × 3지시 × 3모델.

| 확인한 것 | 결과 |
|---|---|
| "간결하게"가 손실을 만드는가 | **그렇다.** 발신자가 번역 지시를 고르는 설계를 유지 |
| 숫자는 보존되는가 | **0/34 소실.** 대조군 지표가 성립 |
| 3언어가 균형적인가 | `mistral-small-3.2-24b`가 방향 간 분산 최소 |
| 언어별 길이 상한 | 실측 `fr : ja : zh = 100 : 33 : 23` |

숫자가 완벽히 보존된다는 것이 중요합니다 — *"번역이 부실해서 실패한 게 아니다"*를 보이는 대조군이 됩니다. 균일 길이 상한을 걸었다면 `fr`이 구조적으로 불리해져 실패 원인을 구분할 수 없었을 것입니다.

### 사전 밸런스 (Phase 0)

LLM 없이 규칙 기반 정책으로 파라미터 공간을 훑어 **세계를 만들기 전에 설계 결함 5건**을 잡았습니다. 단위 오류, 부등식 누락, 스펙 모순(요격기가 구조적으로 도달 불가능했음), 지표 정의 부재, 그리고 사망이 예산을 찍어내던 문제입니다.

캘리브레이션 목표도 여기서 바뀌었습니다. 재앙 회피율을 목표로 삼으려 했지만, 시행 횟수가 많아 진척이 사실상 결정적이 되어 **회피율이 조율 성공률을 그대로 복사**합니다. 파라미터로 움직일 수 없는 양이었습니다. 대신 **필요 기여율 `w*`** — 살아남으려면 소득의 몇 %를 국제 협력에 내야 하는가 — 를 씁니다.

### 본실험

아직입니다. `RESULTS.md`에 조건별 표와 **주장 ↔ 증거 대응표**로 기록하며, 실패도 정직하게 남깁니다.
