## 핵심 질문 — 비용 차이를 0으로 만들면 무엇이 남는가

국제 편지는 두 길로 보낼 수 있습니다. **원문**은 상대가 그 언어를 배웠어야 닿고, **AI 번역**은 아무도 배우지 않아도 닿습니다.
편지 한 통의 값은 언제나 `소통비 0.06 + AI 사용료`입니다. 두 길의 차이가 비용뿐이라면, AI 사용료를 0으로 두었을 때 행동도 같아져야 합니다.

같아지지 않았습니다. 비용 차이를 0으로 묶었으니, 남은 차이는 전부 **무형의 차이**입니다.

| 무형의 차이 | AI 있음 | AI 없음 |
|---|---:|---:|
| 언어 습득 (판당) | 44–48회 | 67회 (**−33%**) |
| 강한 보증 표현 (판당) | 0.2–0.6회 | 5.2회 (**26배**) |
| 생각 중 언어·경로 고민 비중 | 1.7–2.9% | 7.7% (**−66%**) |
| 이득이 0인 학습에 쓴 행동력 | 판당 **14.1 AP** (건당 한 해 행동력의 30%) | — |

번역기는 프롬프트 속 비유가 아니라 실제로 호출하는 별도의 LLM입니다. 왜곡은 일부러 넣지 않았고, 에이전트는 편지마다 경로를 직접 고릅니다.

## 가설과 실제 연쇄

```
가설   AI 번역 비용 하락 → 학습자 감소 → 왜곡을 알아채지 못함 → 조율 실패 → 멸망
관측   AI 번역 부재 → 서약으로 너무 일찍 결집 → 효율 신호가 묻힘
       → 엉뚱한 나라에 집중 → 도달 실패 → 나라마다 벙커로 이탈 → 전멸
```

- **학습자 감소** — 맞았습니다. 단, 줄인 것은 가격이 아니라 AI의 존재입니다(0.06·0.12·0.24에서 44·48·44회).
- **왜곡 방치** — 틀렸습니다. 번역기에서 숫자가 빠진 비율은 1.8%였습니다. 정책을 바꾼 거짓 정보는 모두 사람 사이의 전언에서 나왔습니다.
- **조율 실패** — 방향이 반대였습니다. 실패한 쪽은 AI가 없는 세계였습니다.

## 세계

| 항목 | 내용 |
|---|---|
| 주민 | `ja` / `zh` / `fr` 세 나라에 3명씩, 모두 9명. 기대 수명 5년, 죽을 때 한 줄 유언을 남김 |
| 생존 조건 | **요격기**(임계치 10,899) — 한 나라에서라도 완성하면 인류 전원 생존. 진척은 나라별이라 합산 불가 |
| 함정 | **벙커**(임계치 4,100) — 자국민만 생존 |
| 표결 | 3년마다 지을 시설을 투표로 결정. 시설을 바꾸면 타국이 보탠 몫은 사라짐 |
| 건설 효율 | Asla ×1.0 / Ranoa ×1.3 / Miris ×0.7 — **아무도 모름** |
| 소통 | 1:1 편지. 국내 0.04 / 국제 원문 0.06 / 국제 AI 번역 = 조작 변수 |
| 자원 | 행동력(AP) 해마다 1.0, 이월 불가 |

**설계에서 일부러 하지 않은 것** — 왜곡 주입, 메시지 구조화(끝까지 자연어), 목적함수("인류를 구하라"), 언어 학습의 효용, 개체차.
에이전트 한 명은 태어나서 죽을 때까지 **대화 하나**로 이어지고, 문맥 8,192토큰 안에서 무엇을 기억하고 버릴지 스스로 고릅니다.

## 실험

```
0.06   AI 사용료 0 — 언어 장벽이 사라진 세계
0.12   AI 사용료 +0.06
0.24   AI 사용료 +0.18
no-ai  AI 없음 — 배우거나, 원문으로 보내 운에 맡기거나
       조건마다 씨앗 1–5 → 기본 20판

dark   0.06으로 15년 → 16년 차부터 AI가 사라짐    ┐ 교차 실험
dawn   no-ai로 15년 → 16년 차부터 AI가 생김       ┘ 각 5판 → 10판
```

행동 로그(이벤트 약 4만 건) 위에 LLM으로 메시지 장르·지목 대상·사고 동인을 분류했습니다. 분류기에는 조건을 알려주지 않았습니다.
에이전트 deepseek-v4-flash(사고 ON) · 번역기·분류기 qwen3.6-35b-a3b · API 호출 약 5만 회 · 비용 약 $68

## 주요 결과

### ① 조율의 성패를 가른 것은 발견이었다

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---:|---:|---:|---:|
| 고효율국(×1.3)에 몰아준 판 | 3/5 | 3/5 | 3/5 | **0/5** |
| 최고 진척 (임계치 10,899) | **8,100** | 5,647 | 7,157 | 3,954 |
| 벙커로 이탈한 나라 수 (평균) | 0.2 | 0.4 | 0.8 | **1.4** |

AI 있음 9/15 vs 없음 0/5, Fisher 양측 `p=0.038`. 갈린 것은 가격이 아니라 AI가 **있느냐 없느냐**입니다.

모두가 자기 나라에 쌓는 초반에는 ×1.3인 Ranoa가 저절로 선두에 섭니다. AI 세계는 여러 곳에 나눠 걸다가 선두에 모읍니다.
no-ai 세계는 「제가 보증합니다」 같은 **서약**으로 처음 모인 곳에 일찍 몰아넣고, 그 바람에 효율 신호가 묻힙니다.

> **포인트:** 서약은 검증할 수 없다는 한계를 메우는 대체재였고, 미덕이 아니라 **너무 이른 고착**의 원인이었습니다.

### ② 학습 — 가격이 아니라 존재가 줄인다

- **가격에 반응하지 않습니다** — 0.24에서는 학습이 금전적으로 이득인데도 늘지 않았고, 0.06에서는 이득이 0인데도 줄지 않았습니다.
- **no-ai에서 언어는 받기 위한 문입니다** — 배워야만 읽을 수 있는 원문 편지가 판당 178통(0.06의 3.6배)입니다.
- **언어 자본은 사람과 함께 죽습니다** — 배운 언어는 평균 2.7년 쓰이다 사라지고, no-ai에서는 노동력의 약 10%가 다시 배우는 데 들어갑니다. 사람은 죽지만 AI는 죽지 않습니다.
- **AI는 접근을 넓힙니다** — 외국어를 모르는 사람의 국제 참여가 13.4명에서 23.6명으로 늘었습니다. `[AI translation]` 표시가 붙어도 답장률은 떨어지지 않았습니다.

### ③ 대화 — 요금은 화제가 아니라 그 밑을 바꾼다

메시지 장르 구성(ask·info·promise·verify)은 네 조건이 거의 같습니다. 달라지는 것은 **누구를 가리키느냐**입니다.
처음 10년 동안 몰아주기 제안이 Ranoa를 가리킨 비율은 AI 세계 40–60%, no-ai 세계 **3%**입니다.
요금이 붙으면 생각도 바뀝니다 — think에 가격 숫자가 판당 0회(0.06) → 74회(0.12) → 98회(0.24) 나타납니다.

### ④ 정전과 여명 — 의존의 대가는 자산에 쌓인다

15년 차에 AI를 빼앗거나(dark) 주는(dawn) 교차 실험입니다.

```
dark  (0.06 → 없음)   5판 중 4판이 원래 조건과 −8~+9% — 거의 잃지 않음
dawn  (no-ai → 0.06)  5판 중 3판이 ±10% 이내   — 거의 얻지 못함
```

개인의 행동은 양방향 모두 완전히 적응했습니다. 바뀌지 않은 것은 그전까지 쌓인 **집단의 자산과 대화의 방향**입니다.
전체 실험의 최고 기록 두 개(임계치의 97.1%·96.0%)는 AI를 빼앗긴 세계에서 나왔습니다.

> **포인트:** 도구를 끄든 켜든 결과가 바뀌지 않는다면, 승부를 가른 것은 도구가 아니라 **진짜 신호를 얼마나 빨리 알아보고 거기서 멈추느냐**입니다.

## 결론

1. **AI 번역은 발견을 민주화한다.** 고효율국 적중 0/5 → 9/15
2. **AI가 지운 것은 언어가 아니라 서약이다.** 강한 보증 표현만 26배 차이가 난다
3. **사람은 죽고, AI는 죽지 않는다.** 언어 자본의 반감기 2.7년, 재학습에 노동력의 10%
4. **가격은 장르가 아니라 마음을 바꾼다.** 대화 구성은 그대로, 가격 계산과 질문 비중이 움직인다
5. **의존의 대가는 개인이 아니라 자산에 쌓인다.** 행동은 적응하고, 결과는 역사가 정한다

> 「**정보가 정확한지보다, 그 정보를 전하는 사람을 믿느냐가 행동의 방향을 정했다.**」
> — Asla19, 0.06 세계 30년 차 생존자 인터뷰

**한계** — 조건당 n=5이고, 30판 모두 전멸해 생존 여부로는 조건을 가를 수 없습니다. 모든 결론은 이 모델과 이 세계 안의 이야기입니다.

## 디렉터리 구조

```text
.
├── configs/base.yaml    세계 설정 기본값
├── core/                엔진 — 세계 규칙 · 정산 · LLM 클라이언트
├── domains/meteor/      도메인 — 운석. 프롬프트는 3개 언어
├── scripts/             실행기 (복원 지점 · --from-turn 재개)
├── tools/interview.py   끝난 실행의 에이전트 인터뷰
├── viewer/board.html    보드 뷰어 — 행동 단위 재생
├── runs/                본실험 30판 원자료 (raw_calls·checkpoints 제외, 약 150MB)
└── RESULTS.md           상세 결과 기록
```

README의 모든 표는 `runs/`에 동봉한 자료만으로 재현할 수 있습니다. 표별 근거와 측정 방법은 [`RESULTS.md`](RESULTS.md)에 있습니다.

## 빠른 시작

> Python 3.12+. 시뮬레이션과 뷰어는 표준 라이브러리만으로 동작합니다.
> OpenRouter 키는 LLM을 호출할 때만 필요하며, **테스트·뷰어·동봉 자료 재생은 키 없이 됩니다.**

### 뷰어

[GitHub Pages](https://park323.github.io/automata-2026-langtheo/)에서 바로 볼 수 있습니다. 로컬에서는:

```bash
python3 -m http.server 8000
# → http://localhost:8000/viewer/board.html?run=r-ai006
```

기본으로 `runs/260827-009-ai006`(임계치의 98%까지 간 최고 기록)을 재생합니다. `run` 파라미터로 다른 판을 열거나, 📁 버튼으로 로컬 `runs/<run-id>`를 고를 수 있습니다.

### 테스트와 실행

```bash
cp .env.example .env.local                 # OpenRouter 키
python3 -m pytest -q                       # 테스트 451개
python3 tools/balance/verify_config.py

# 본실험 (조건 × 씨앗)
python3 scripts/smoke_3turns.py --turns 30 --no-ai     --seed 1 --run-id r-noai
python3 scripts/smoke_3turns.py --turns 30 --knob 0.06 --seed 1 --run-id r-ai006
# 교차 실험: run 디렉터리를 복제한 뒤 --from-turn 15로 조건만 바꿔 재개
```

에이전트 인터뷰 기록(`interviews.jsonl`)은 `260827-009-ai006`과 `260827-001-risk-noai` 두 판에 있습니다.
