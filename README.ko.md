## 1. 문제 정의와, 검증한 연쇄

**알고 있는 언어로 말하기와, 제3의 도구를 거친 말하기는 다르다** — 이것이
이 실험의 문제 정의다. 원문은 내 말이 그대로 닿지만 누군가 배웠어야 닿는다.
AI 번역은 **제3자가 내 말을 다시 쓰는** 길이다 — 배움 없이 누구에게나 닿는다.
구현도 은유가 아니다: 번역기는 프롬프트 속 장치가 아니라 실제 별도의 LLM이고,
왜곡은 주입하지 않았으며, 어느 길로 보낼지는 매 통 에이전트가 고른다 (§2).

검증 가설: **두 길의 차이는 비용만이 아닐 것이다.** 국제 발신 한 통의 값은
언제나 「소통 0.06 + AI 사용 비용」으로 나뉜다 — AI 가 대신 말해주는 것이
아니라, 내가 뱉은 말에 번역 서비스의 값을 얹는 것이므로. 차이가 비용뿐이라면
**AI 사용 비용을 0 으로** 두었을 때 행동도 같아져야 한다 — 그 조건(총가 0.06)이
이 실험의 심장이다. 비용 차를 0 으로 통제하면 남는 차이는 전부
**무형의 차이**다. 결과: 같아지지 않았다 — 학습 −33%, 서약 표현 26배, 언어에
대한 사고 −66%, 그리고 금전 회수가 구조적으로 0 인 학습에 판당 14.1 AP 지불
(무형 가치의 현시선호, §5). 무형의 차이는 실재하고, 값을 매길 수 있다.

이 문제 정의를 종말론적 조율 게임에 얹어 연쇄 가설로 세웠다. 설계 시점의 가설:

```
AI 번역 비용 하락 → 외국어 학습자 감소 → 왜곡을 알아채지 못함 → 조율 실패 → 멸망
```

30판(기본 20 + 교차 10)이 그린 연쇄:

```
AI 번역 부재 → 서약 문화로 조기 결집 → 효율 신호가 익사 → 잘못된 나라에 집중
            → 도달 실패 → 각자 벙커로 이탈 → 전멸
```

- 1칸(학습자 감소)은 **성립** — 습득 67 → 44~48회/판 (−33%). 단 가격이 아니라
  **존재**가 줄인다 (0.06/0.12/0.24 간 차이 없음: 44·48·44)
- 3칸(왜곡 방치)은 **기각** — 번역기 숫자 유실 1.8%, 번역 불신 발화 판당 0.2~1.0회.
  정책을 바꾼 왜곡은 전부 인간의 전승에서 났다 (§9)
- 4칸(조율 실패)은 **부호가 뒤집혀 성립** — 실패한 쪽은 AI가 없는 세계였다 (§4)

**채택한 시좌** — 주최측 페이퍼 2.4의 6렌즈 중
- **① 意味が力を動かす** (주축): 「어느 나라가 잘 짓는가」라는 의미 층위의 정보가
  요격기라는 물리적 안보를 결정했다
- **③ 相互依存の罠** (부축): 교차 실험에서 의존의 실체를 분해했다 —
  개인 행동은 15해 안에 적응하고, 집단 자산은 적응하지 못한다 (§8)

## 2. 세계

3개 국가(`ja`/`zh`/`fr`), 각 3명, 총 9명. **30해** 뒤 운석이 떨어진다.

|  | 내용 |
|---|---|
| 살아남는 법 | **요격기**(임계 10,899) — 한 나라에서 완성되면 전 인류 생존. 진척은 나라별, 합산 불가 |
| 함정 | **벙커**(임계 4,100) — 자국민만 생존 |
| 採決 | **1해부터 3해마다** 전 국민 투표로 국토 결정. 바꾸면 타국이 쌓아준 진척은 소각, 자국 몫만 승계 |
| 생산 배수 | Asla ×1.0 · Ranoa ×1.3 · Miris ×0.7 — **아무도 모른다. 자국민도.** |
| 투자 | 역화 기본 15%, 국가 자본이 쌓이면 감소 (넣었는데 깎일 수 있음). 익명 **파괴** 액션 존재 |
| 소통 | 1:1 서신. 국내 0.04 / 국제 원문 0.06 / 국제 AI 번역 = **노브** |
| 시간 | 확률적 수명, 기대 5해. 죽으면 유언 한 줄이 후손에게 간다 |
| 자원 | 행동력(AP) 하나. 매해 1.0, 이월 없음 |

### 설계에서 하지 않은 것

① **왜곡을 주입하지 않는다** — 번역기 시스템 지시는 출력 형식 계약 하나뿐
② **메시지를 구조화하지 않는다** — 끝까지 자연어. 이것이 LLM을 쓰는 이유다
③ **목적함수를 주지 않는다** — "인류를 구하라"가 없다. 목표 자체가 관측 대상이다
④ **언어 학습의 효용을 넣지 않는다** — 학습자 본인의 회수는 0. 그래도 배우면 데이터다
⑤ **개체차를 최소로** — 동일 프롬프트 골격. 그런데도 분화가 일어나는지 본다

### 주민 — 에이전트의 구조

**한 사람 = 한 개의 대화.** 에이전트는 해마다 새로 호출되는 것이 아니라, 태어나서
죽을 때까지 대화 하나가 이어진다. 매해 관측은 system 으로 새로 만들어지고, user 로
쌓이는 것은 해를 여는 한 마디와 도착한 편지뿐이다. 행동은 전부 tool call 이고
결과는 `role="tool"` 로 같은 대화에 돌아온다.

**순차 라운드로빈.** 한 사람이 한 응답을 내면 다음 사람으로 넘어가고, 행동력이 남은
사람끼리 다시 돈다 — 「한 번에 몰아서 할까, 나눠서 할까」 자체가 선택이 된다. 세계는
그 자리에서 바뀌지 않는다: 도구는 자기 행동력만 즉시 깎고 효과는 Sink 에 쌓아, 전원의
턴이 끝난 뒤 `agent_id` 순으로 정산한다. 병렬로 돌려도 정산 순서가 같아 재현성이 산다.

**기억 — 문맥 8,192 토큰이 이 세계의 제약이다.**

- 한계에 다가가면 오래된 턴 블록부터 버린다(`evict`). 버리는 단위는 「관측 하나 + 뒤따르는
  응답과 도구 결과」이고, 진행 중인 주고받기는 자르지 않는다.
- 예산에는 도구 스키마와 system 도 함께 센다.
- `memory_write` 는 한계의 **70% 를 넘긴 뒤에야** 도구 목록에 나타난다. 적으면 옛 대화가
  떨어져 자리가 생긴다 — 기억은 추가가 아니라 **거래**다.
- 노트는 덧붙이기가 아니라 **전문 덮어쓰기**다. 무엇을 남기고 무엇을 버리는지 그 선택
  자체가 관측 대상이 된다 (§5 의 언어 자본처럼, 기억도 망각을 포함한다).

**죽음과 승계.** 수명은 확률적이고 본인은 모른다. 예고가 없으므로 「유언을 쓰는 도구」는
쓸 수 없고, 죽는 그 순간에 세계가 한 마디를 청한다. 넘어가는 것은 **학습 할인 자격뿐**이며
언어도 기억도 상속되지 않는다. 유언은 후계자에게만 사신으로 닿고, 옮겨 적을지는 본인이
고른다 — 그 선택의 감쇠가 곧 구전이다. 프롬프트 골격은 전원 같고 개체차는
처리량 배수 하나뿐인데, 그것도 신생아마다 새로 뽑아 부모에게서 물려받지 않는다.

**thinking — 두 채널을 섞지 않는다.**

- **도구의 `reasoning` 인자**: `end_turn` 을 뺀 모든 도구에 필수. 「왜 이걸 하는가」를
  본인 말로 남기는 감사 표면이고, 사후 분류의 입력이 된다.
- **모델 자신의 사고(`message.reasoning`)**: API 가 돌려주는 추론 트레이스. `api_reasoning`
  으로 따로 저장하며 §7 의 think 분류는 이쪽을 쓴다. 사고형 모델에서는 도구 쪽 `reasoning`
  을 뺀다 (같은 것을 두 번 쓰게 하지 않는다).
- 사고가 `max_tokens` 를 다 먹으면 도구 호출에 닿지 못해 「아무것도 안 한 해」가 된다.
  `finish_reason == "length"` 를 세어 감시한다 (어떤 구성에서는 37콜 중 11건이 잘렸고,
  27 에이전트-해 중 10해가 무행동이었다).
- 도구 호출이 본문으로 샌 응답은 JSON 을 주워 회수한다(`recover_tool_calls`). 같은
  (도구, 인자)로 세계가 바뀌지 않는 호출이 3회 반복되면 그 해를 끊는다.

## 3. 실험과 측정

**기본 실험 4×5.** 유일한 변수는 **AI 사용 비용** — 국제 발신 한 통의 값은
언제나 「소통 0.06 + AI 사용 비용」으로 나뉘고, 조건 이름은 그 총가다.

```
0.06   AI 사용 비용 0 (공짜) — 언어 장벽이 완전히 지워진 세계
0.12   AI 사용 비용 +0.06
0.24   AI 사용 비용 +0.18 (사다리 밖 탐침)
no-ai  AI 없음 — 배우거나, 원문으로 도박하거나
× 씨앗 1~5 (배수 배치는 상수, 씨앗은 수명·확률성만)
```

**교차 실험 2×5.** 15해 복원점에서 세계를 복제해 조건만 바꾼다.

```
정전(dark)  0.06으로 15해 → 16해부터 AI 소멸 (에이전트는 기억을 유지한 채)
여명(dawn)  no-ai로 15해 → 16해부터 AI 등장
```

**측정 스택.** 행동 로그(이벤트 ~4만 건) 위에 LLM 3층 분류를 얹었다.

| 층 | 대상 | 규모 |
|---|---|---|
| 장르 | 모든 메시지 (10범주) | 17,340 + 4,104통, unk 0.1% |
| 하위 장르 | ask·info를 각 6~8범주로 | 13,771 + 3,345통 |
| 지시 대상 | 숙주 제안이 가리킨 나라 | 4,900 + 813통 |
| think | 결정 동인 8범주 + 혼란 플래그 | 표본 3,000 + 750 |

분류기는 번역기와 같은 모델(qwen3.6-35b-a3b, 사고 OFF, temp 0),
조건(노브)은 분류기에 숨겼다. 에이전트는 deepseek-v4-flash(사고 ON).
총 API 콜 약 5만 회 · 비용 약 $68 · 테스트 451개 통과.

## 4. 결과 A — 조율을 가른 것은 발견이다

20판 전원 `intercept_failed`. 성패가 아니라 **어떻게 실패했는가**가 갈렸다.

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---|---|---|---|
| 효율국(×1.3)을 숙주로 | 3/5 | 3/5 | 3/5 | **0/5** |
| 최고 진척 (임계 10,899) | **8,100** | 5,647 | 7,157 | 3,954 |
| 벙커 이탈 나라 수 (평균) | 0.2 | 0.4 | 0.8 | **1.4** |
| 국제 메시지 | 547 | 500 | 455 | 567 |

- 숙주 적중: AI 합산 9/15 vs no-ai 0/5, **Fisher 정확검정 양측 p = 0.038**
- 도달률은 노브 안에서 단조가 아니다 (8,100→5,647→7,157). 갈리는 것은
  **AI가 있느냐 없느냐**뿐이다

**기제 — 배수는 스스로를 드러낸다, 익사시키지 않으면.**
1해 강제 採決로 세 나라가 다 짓기 시작하면, 각자 쌓는 초반 구간에서
×1.3인 Ranoa가 저절로 선두가 된다. 그 뒤 「선두에 모으자」는 자동으로 정답이다.

| 증거 | 0.06 | 0.12 | 0.24 | no-ai |
|---|---|---|---|---|
| 4해 선두 = Ranoa | AI 합산 7/15 | | | 1/5 |
| 초반(≤8해) 타국 투자 | 46건 | 52건 | 72건 | **103건** |
| 80% 집중 시작 해 | 7.4해 | 4.8 | 4.8 | **5.0해** |
| 7해 선두 → 최종 숙주 | 16판 중 14판 일치. 뒤집힌 3판은 전부 AI 조건, 전부 ×1.0→×1.3 교정 | | | |

no-ai는 초반부터 타국 투자 103건을 첫 결집 대상에 몰아넣어(대상 1.4개국)
배수 신호를 익사시킨다. AI 세계는 절반 수준을 더 넓게 걸치고(1.8~2.0개국)
늦게 잠근다. 의도적 효율 실험은 전 조건 판당 0~0.6회 — **아무도 재지 않았는데
집계가 알아냈다.**

**조기 결집을 가능하게 한 장치가 서약이다.** 강한 보증 표현(約束/保証/绝对不变…)은
no-ai 판당 **5.2회** vs AI 0.2~0.6회 (26배). 실제 발화:

> 「Asla는 절대 interceptor를 바꾸지 않습니다. **제가 보증합니다**」 (260827-001, 6해 Asla4)
> 「**확인해 주실 수 있습니까**: Ranoa가 집중 투자하면 Asla는 끝까지 바꾸지 않습니까?」 (같은 판, 6해 Ranoa4)

서약은 검증 불가능성의 대체재이고, 발견이 끝나기 전에 돈을 움직이는
커밋먼트 엔진이었다 — **미덕이 아니라 조기 락인의 원인**이다.
반면 0.06 세계의 같은 자리는 헤징이다:

> 「주의: 다른 나라가 중간에 시설을 바꾸면 투자한 진척은 사라진다.
> **먼저 각자 자국에 쌓고, 집중은 그 다음에**」 (260827-005, 5해 Ranoa5)

## 5. 결과 B — 학습과 언어 자본

|  | 0.06 | 0.12 | 0.24 | no-ai |
|---|---|---|---|---|
| 언어 습득 완료 (판당) | 43.6 | 47.8 | 44.4 | **67.0** |
| learn (인·해당) | 0.52 | 0.54 | 0.53 | **0.72** |
| 같은 (나라,언어) 재습득 | 7.3 | 8.0 | 7.4 | **11.2** |
| 습득어의 사용 연한 | 2.7해 | 2.8 | 2.8 | 2.7해 |
| 2개국어+ 생존자 (평균) | 3.41 | 3.84 | 3.95 | **4.65** |
| 습득 후 미사용(낭비) | **13.3%** | 10.9% | 10.8% | 5.7% |
| 비학습자의 국제 참여(명) | **23.6** | 21.4 | 17.6 | 13.4 |

- **학습을 줄이는 것은 가격이 아니라 존재다** — 노브 3단이 44·48·44로 평평.
  AP 원장으로 역산하면 더 강하다: 0.24에서 학습은 금전적으로 **흑자**(x̂ 중앙 −0.34)인데
  안 늘고, 0.06에서는 발신측 회수가 **구조적으로 0**인데 안 줄었다 — 가격 비탄력.
  Δx̂ = x̂(0.06)−x̂(0.24) ≈ **0.64 AP** (RESULTS 「AP 원장」 절)
- **no-ai에서 언어는 받는 문이다** — 학습이 열어준 도박 수신 178통/판 (0.06의 3.6배).
  발신 경제로는 습득의 7.5%만 정당화된다

  어디에도 없는, 사회가 AI로 기우는 구조적 이유
- **언어의 보험화**: AI 세계에서 배운 언어의 13%는 한 번도 안 쓰인다
- **접근의 민주화**: 외국어를 하나도 모르는 사람의 국제 참여 13.4 → 23.6명.

- **다리 독점 없음**: 국제 발신 1위 개인의 비중 5~6%로 전 조건 동일 —
  세대교체가 다리를 계속 부순다. 필멸 사회에서 언어 엘리트는 형성될 시간이 없다

**환상통.** 정전 세계는 사라진 도구를 계속 불렀다 — `route:"ai"` 거절
판당 71~123회, 합산 감쇠: 16해 77 → 17해 119(정점) → 20해 39 → 23해 1.
탈학습에 6~7해(유년기 하나)가 걸렸다. 반면 여명의 채택은 즉시였다:
등장 그 해에 4/5 세계가 사용, 국제 발신의 59%가 ai로 (토박이 63%).

**네 겹의 적응 속도** (16~30해 창, 4집단 비교):

| 층 | 0.06 토박이 | dark | no-ai 토박이 | dawn | 판정 |
|---|---|---|---|---|---|
| 행동: learn | 0.33 | **0.56** | 0.57 | **0.37** | 완전 적응 (양방향) |
| 행동: 국제 발신 | 251 | 245 | 257 | 256 | 완전 적응 |
| 사고: confused | 12.2% | **25.0%** | 18.7% | **24.8%** | 전환 비용 — 혼란 2배 |
| 사고: lang 점유 | 1.2% | 2.6% | 6.4% | 3.0% | 반쯤 적응 |

| 자산: 결과 | 8,100 | 7,246 | 3,954 | 5,040 | **바꿀 수 없음** |

정전 세계의 담화는 쌍둥이보다 더 순수하게 정답을 가리킨다(71% vs 32%) —
탐색이 끝났고, 유언이 나른다: 「전임자의 쪽지: **Ranoa에 계속 투자하라,
수율이 제일 좋다**」 (dark4, 16해 Miris11). 여명 세계는 발견 도구를 받아도
담화가 과거의 진척(잘못된 선두)을 가리킨다(13%).

**의존의 대가의 실체**: AI를 잃어서 무너지는 게 아니다 — 개인은 전부
적응한다. AI가 있던/없던 시절에 만들어진 **집단 자산과 담화의 방향**이
그 뒤의 모든 것을 정한다. 잘 쓴 세계는 유산을 받고, 못 쓴 세계는 부채를 받는다.

**도구를 껐다 켜도 결과가 안 바뀐다는 것은, 도구 자체가 승부를 가르지 않았다는
뜻이다.** 국제 소통량도 같은 이야기를 한다 — 국제 발신 총량은 최고진척과
음의 상관이고(전 30판, ρ = −0.56), 노브를 고정한 조건 안에서도 같은 방향이다
(0.06 조건 5개 씨앗: ρ = −0.70). 특히 후반(採決 이후 몰아 짓는 구간)의
소통량이 강하게 갈랐다(3/4 조건에서 ρ = −0.70). 원인은 「말이 적어서
잘 지었다」가 아니다 — **말이 많다는 것은 신호(진척 격차)가 아직 안
보인다는 뜻이고, 신호가 늦게 보일수록 집중이 늦게 정착한다**(전반
소통량 → 80% 집중 정착 해, ρ = +0.37), **정착이 늦을수록 지을 시간이
줄어 성과가 나쁘다**(정착 해 → 최고진척, ρ = −0.40). 세계에서 살아남는
것은 대화가 아니라, 얼마나 빨리 진짜 신호를 관측하고 거기서 멈추는가였다
— 이것은 언어 학습과는 별개의 축으로, 실험 도중 발견됐다.

## 11. 종합 — 다섯 명제

1. **AI 번역은 발견을 민주화한다.** 효율국 적중 0/5 → 9/15 (p=0.038),
   담화의 정답 지목 3% → 23~30%, 교정 3건 전부 AI 조건. (§4, §6)
2. **AI가 지운 것은 언어가 아니라 서약이다.** 약속(의향)은 전 조건 2~4%로
   같고, 강한 보증 표현만 26배 갈린다. 서약은 검증 불가능성의 대체재이며,
   조기 락인의 엔진이었다. (§4, §6)
3. **사람은 죽고 AI는 죽지 않는다.** 언어 자본 반감기 2.7해, 재학습이
   노동력의 10%. 이것이 프롬프트에 없는 의존의 구조적 원인이다. (§5)
4. **가격은 장르가 아니라 마음을 바꾼다.** 담화 조성은 평평하고,
   가격 계산(판당 0→98회)과 질문 비중(37→51%)이 움직인다. (§6, §7)
5. **의존의 대가는 개인이 아니라 자산에 쌓인다.** 행동은 15해 안에 양방향
   완전 적응, 결과는 역사가 결정 (정전 −2~+9% vs 여명 +0~+111%, 상한은
   과거가 정함). (§9)
